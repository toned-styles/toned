# 0.1.0

First release.

### Added

* **Source index.** A bounded index of systems, stylesheets, parts and token uses across a workspace, with version-checked edit proposals. ([Source intelligence](https://toned.style/learn/source))
* **Language server.** `toned-lsp` provides diagnostics, completions, hover, definitions, references and rename. ([Compiler and language server](https://toned.style/learn/compiler))
* **`@toned/compiler/language-service`.** The same service as a library, with no Node dependencies, for editors that run in a browser.
* **Design inspector** and its development source bridge. ([Design inspector](https://toned.style/learn/inspector), [Development source bridge](https://toned.style/learn/bridge))
* **DTCG token exchange.** Import, resolve and export the supported subset of the Design Tokens format. ([DTCG token exchange](https://toned.style/learn/tokens))
* **Design contracts.** Scenarios evaluated against measured geometry. ([Design contracts](https://toned.style/learn/contracts))
